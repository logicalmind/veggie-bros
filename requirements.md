Build a complete, playable 2D side-scrolling platformer inspired by the feel and core mechanics of the original NES Super Mario Bros., with a fruit-and-vegetable theme.

First inspect the existing project and use its current language, framework, and conventions. If it is empty, choose a simple setup that can run locally in a browser. Implement the game in the project; don’t stop at a design document or mockup.

GAME CONCEPT
The hero is a small fruit or vegetable on a quest through colorful gardens and food-themed worlds. Replace the familiar cast and objects with original produce-themed characters and designs—for example, a strawberry hero, mushroom-like vegetables, walking turnips, and a pineapple boss. Give everything original names and visual details.

GAMEPLAY
- Side-scrolling movement with responsive left/right controls, running, jumping, and collisions.
- Platforms, gaps, pipes or other themed passageways, coins or collectible produce, and destructible blocks.
- Enemies with simple patrol behavior that the player can avoid or defeat by jumping on them.
- A power-up that changes the player’s size or grants a temporary ability.
- A goal at the end of each level and a transition to the next level.
- Lives or another clear failure-and-retry loop, plus a score or collectible counter.
- A title screen, pause/restart option, and clear win/game-over screens.

ORIGINALITY
Create original character art, environments, names, sound effects, music, and level layouts. Do not use Nintendo or Mario branding, sprites, copied audio, or exact level maps. Aim for an 8-bit-inspired look and similarly brisk platforming, while making the world and content distinct.

PRESENTATION
Use crisp pixel-art-style visuals, a readable camera, clear animations, and sound effects or simple original music if the project supports audio. Make the game playable with keyboard controls and show the controls on the title or pause screen. If practical, support touch controls on small screens.

FINISHING
Make the main path from starting the game to completing a level work end to end. Keep the code organized, handle restarts and level transitions cleanly, and include concise instructions for running the game and its controls. Before finishing, launch the project and make sure the core gameplay is usable.
