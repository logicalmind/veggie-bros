Browser, and the **only** way to reach `dpr > 1`: `tab.emulate({ device: 'iPhone 13' })` on a Chromium tab (`app: 'chromium'`) gives `window.devicePixelRatio === 3`; WebKit's `emulate` silently ignores `deviceScaleFactor` and Chromium's `open({ viewport: { deviceScaleFactor } })` ignores it too. `emulate({ device })` does not re-apply the scale after an explicit `emulate({ viewport })` — re-open the tab. In the hidden shared Chromium tab rAF is frozen between automation calls (looks like a dead game loop; wake it with a `page.evaluate` rAF sampler) and `tab.evaluate(string)` runs in an isolated world (`window.__*` stashes never return, `console`/`errors` come back empty) — use `tab.run` with `return await page.evaluate(…)`. On WebKit (`app: 'own'`) the opposite holds: `tab.evaluate(asyncIIFE)` returns `undefined` so stash on `window.__*` and read it back in a second call; `tab.screenshot({ path })` writes nothing (use canvas `toDataURL`); `tab.evaluate(() => location.reload())` fails (use `tab.reload()`); a released `press('ArrowRight')` leaves `cam.x === 0` (`press('Enter')` then `keyDown('ArrowRight')` **held**); `window.G` is a module export, not a global.
